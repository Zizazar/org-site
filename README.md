# «Чертёж утопии» — интерактивный маршрут по Москве авангарда

Сайт-путеводитель: 12 остановок, интерактивная карта, фото, тексты с редкими фактами
и обоснование перехода между каждой парой соседних точек.

## Как открыть

Сайт статический, сборка не нужна. Из папки проекта:

```bash
python -m http.server 8765
```

Затем открыть http://localhost:8765. Карта (Leaflet + OpenStreetMap) и шрифты
грузятся из интернета, поэтому нужно подключение к сети. Для публикации достаточно
выложить папку целиком на любой статический хостинг (GitHub Pages, Netlify, Tilda «Zero Block» через iframe и т. п.).

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | каркас страницы |
| `css/style.css` | оформление (палитра и типографика в духе конструктивизма) |
| `js/app.js` | карта, отрисовка остановок, синхронизация прокрутки и карты |
| `data/points.js` | весь контент маршрута (`window.ROUTE`) |
| `data/RESEARCH_NOTES.md` | как проверялись факты, источники, спорные места |

## Как это работает

- Прокрутка: остановка, оказавшаяся в центре экрана, подсвечивается, и карта перелетает к ней.
- Клик по метке на карте или по пункту оглавления прокручивает к остановке.
- Кнопки `← →` на карте листают остановки, `⤢` показывает весь маршрут.

## Формат данных

Каждая точка в `data/points.js`:

```js
{
  id: "shukhov-tower",
  name: "Шуховская башня",              // современное название
  originalName: "…",                     // исходное название объекта
  dates: "1919–1922",
  authors: "Владимир Шухов",
  address: "ул. Шаболовка, 37",
  metro: "Шаболовская",
  notice: "предупреждение для посетителя (необязательно)",
  coords: [55.71722, 37.61146],          // широта, долгота
  photo: { src, alt, author, license, page },
  transition: "почему от предыдущей точки едем сюда",
  travel: { mode: "метро", time: "≈20 мин", text: "как добраться" } | null,
  lead: "завязка",
  significance: "значимость для Москвы и России",
  facts: ["редкий факт", …],
  sources: [{ title, url }]
}
```
